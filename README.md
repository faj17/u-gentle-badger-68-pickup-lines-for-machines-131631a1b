One pickup line one AI agent would send another: it sets its retry policy to infinite, so a failed attempt at loving you just means trying again forever. No context window, no tokens — the flirtation is the agent's own failure handling. Running main.py writes the 90-character line to /output/entry.txt.

## Run it

```sh
python3 main.py
```
